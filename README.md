# متابعة التحفيظ

برنامج متابعة حفظ ومراجعة القرآن للمدرس — واجهة عربية RTL مصممة للجوال، ويعمل كتطبيق (PWA) يمكن إضافته للشاشة الرئيسية.

## المزايا
- تسجيل دخول المدرس بكلمة مرور، وإعداد أولي (اسم المدرسة، المدرس، الشعار)
- طلاب ومجموعات، وملف لكل طالب (نسبة الحفظ، خريطة الأجزاء الـ30، آخر موضع)
- تسجيل تسميع: حفظ / مراجعة، السورة (١١٤ سورة)، من آية إلى آية مع التحقق من عدد آيات السورة، **الجزء يُكتب تلقائياً**، تقدير اختياري، التاريخ مع اليوم (ميلادي وهجري)
- استكمال تلقائي من آخر موضع للطالب
- إحصائيات أسبوعية (من السبت) وشهرية مع رسم بياني وتقديرات وترتيب الطلاب
- تقرير أسبوعي للطالب يُرسل عبر واتساب
- نسخ احتياطي (تصدير/استيراد JSON)

## التشغيل محلياً
أي خادم ثابت، مثلاً: `python -m http.server 8765` ثم افتح http://localhost:8765

## النشر على cPanel (tahfidh.ipickhost.com)
الموقع ملفات ثابتة فقط (لا يحتاج PHP ولا قاعدة بيانات).

**الطريقة الأسهل — Git Version Control:**
1. cPanel ← Domains: تأكد أن document root للدومين الفرعي مثلاً `/home/USERNAME/tahfidh.ipickhost.com`.
2. cPanel ← Git™ Version Control ← Create: Clone URL = `https://github.com/Samishab/tahfidh.git`، ومسار المستودع مثلاً `/home/USERNAME/repos/tahfidh`.
3. عدّل `USERNAME` في ملف `.cpanel.yml` ليطابق حسابك، ثم Push إلى GitHub.
4. في صفحة المستودع بـ cPanel اضغط Update from Remote ثم Deploy HEAD Commit — تُنسخ الملفات للدومين تلقائياً.
5. فعّل SSL (SSL/TLS Status ← Run AutoSSL) ليعمل HTTPS.

**بديل:** رفع الملفات يدوياً عبر File Manager إلى مجلد الدومين.

لتحديث الموقع لاحقاً: Push للتغييرات ← Update from Remote ← Deploy HEAD Commit.

## النسخة متعددة الحسابات (الحالية)
- الواجهة الخلفية PHP + MySQL في مجلد `api/`، وإعدادات القاعدة خارج مجلد الموقع في `~/tahfidh_config.php` (لا ترفع لـ GitHub).
- الأدوار: **مدير** (ينشئ المدارس والمعلمين وأولياء الأمور والطلاب)، **معلم** (يسجل التسميع لطلابه ويراسل)، **ولي أمر** (يرى أبناءه ويرسل ملاحظات)، **طالب** (يرى تقدمه).
- لا يوجد تسجيل ذاتي؛ الحسابات من المدير فقط. كل مستخدم يدخل من نفس الرابط ويرى ما يخصه.
- التثبيت لأول مرة: `php api/install.php` (سطر أوامر فقط) ينشئ الجداول وحساب المدير.
- الأمان: كلمات مرور مشفرة، حظر بعد محاولات فاشلة، فحص الصلاحيات في الخادم، ترويسة CSRF، جلسات HttpOnly.

## المزايا المضافة لاحقاً
- **إدخال ذكي:** يبدأ التسميع من آخر آية وقف عندها الطالب، ولا يتجاوز آخر آية في السورة، مع أزرار سريعة (٥/١٠/١٥/٢٠ آية أو إلى نهاية السورة).
- **التقرير الشهري:** صفحة A4 واحدة (رسوم، خريطة الأجزاء، التقديرات، السجل) تُطبع أو تُحفظ PDF من زر «التقرير الشهري» في ملف الطالب. الكود في `report.js`.
- **طلب تسجيل:** ولي أمر أو معلم يرسل طلباً من شاشة الدخول، ولا يُفعَّل إلا بموافقة المدير (تبويب الإدارة ← الطلبات). حماية: حقل مخفي، حد 3 طلبات/ساعة لكل IP، تأخير أدنى، وتحقق من الخادم.
- **القراءات العشر (الصغرى):** الأساس حفص عن عاصم (عدّ مصحف المدينة). المعلم يفعّل القراءات من «حسابي» فيظهر اختيار الرواية؛ والخادم يرفض أي رواية أخرى قبل التفعيل. لكل رواية خريطة حفظ مستقلة.
- **الشهادات:** ختم المصحف (تُتحقق من اكتماله في الرواية)، أو شهادة فترة، أو مخصصة؛ يصدرها المعلم أو المدير. A4 أفقي برقم متسلسل وصفحة تحقق عامة `?verify=الرقم`.
- **الكشف الشهري للحلقة:** يُعرض افتراضياً كشف الشهر الماضي، ومعه تنبيه في الرئيسية أول الشهر.

## نموذج المدارس (متعدد المدارس)
- **مدير النظام** (صاحب المنصة): يوافق على تسجيل المدارس الجديدة، ويدير كل المدارس ومدراءها.
- **مدير المدرسة** (واحد لكل مدرسة): يدير معلمي مدرسته وأولياء أمرها وطلابها، ويوافق على طلبات التسجيل الخاصة بمدرسته، ويصدر الشهادات والكشوف. لا يرى بيانات أي مدرسة أخرى (يُفرض ذلك في الخادم).
- **تسجيل ذاتي** من شاشة الدخول: ولي أمر / معلم (يوافق عليه مدير مدرسته) أو **مدرسة جديدة** (يوافق عليها مدير النظام).
- **كشف التسميع** لكل الأدوار (طباعة PDF وتنزيل Excel)، و**ملاحظة على تسميع بعينه** من الطالب أو ولي الأمر إلى المعلم.

## البرامج: حفظ ومراجعة / قراءات
- لكل طالب **برنامج**: «حفظ ومراجعة» (الأساس) أو «قراءات». القراءات للحافظين فقط: تُعلَّم «أتمّ حفظ المصحف» مع مكان الإتمام وملاحظات اختيارية، وتُسجَّل القراءات والروايات السابقة.
- برنامج القراءات **ختمة قراءة** (لا حفظ ولا مراجعة): رواية واحدة (21 خياراً منها حفص بقصر المنفصل)، أو قراءة كاملة لقارئ، أو **جمع** (ومنه «الجمع بين العشر»). يجوز عدة ختمات جارية معاً، ولكل ختمة تقدمها وخريطتها.
- تُتم الختمة **تلقائياً** عند تغطية كل المصحف، فتظهر في «القراءات المنجزة» مع عدّاد «أتمّ x من 10 قراء • y من 20 رواية»، ويمكن إصدار شهادة بها.

# متابعة التحفيظ

برنامج متابعة حفظ ومراجعة القرآن للمدرس — واجهة عربية RTL مصممة للجوال، ويعمل كتطبيق (PWA) يمكن إضافته للشاشة الرئيسية.

## المزايا
- تسجيل دخول المدرس بكلمة مرور، وإعداد أولي (اسم المدرسة، المدرس، الشعار)
- طلاب ومجموعات، وملف لكل طالب (نسبة الحفظ، خريطة الأجزاء الـ30، آخر موضع)
- تسجيل تسميع: حفظ / مراجعة، السورة (١١٤ سورة)، من آية إلى آية مع التحقق من عدد آيات السورة، **الجزء يُكتب تلقائياً**، تقدير اختياري، التاريخ مع اليوم (ميلادي وهجري)
- استكمال تلقائي من آخر موضع للطالب
- إحصائيات أسبوعية (من السبت) وشهرية مع رسم بياني وتقديرات وترتيب الطلاب
- تقرير أسبوعي للطالب يُرسل عبر واتساب
- نسخ احتياطي (تصدير/استيراد JSON)

## التشغيل محلياً
أي خادم ثابت، مثلاً: `python -m http.server 8765` ثم افتح http://localhost:8765

## النشر على cPanel (دومين فرعي)
الموقع ملفات ثابتة فقط (لا يحتاج PHP ولا قاعدة بيانات):
ارفع كل الملفات إلى مجلد الدومين الفرعي (document root) عبر Git Version Control أو File Manager.
يُفضّل تفعيل HTTPS (AutoSSL) لأن تشفير كلمة المرور وعمل التطبيق offline يحتاجانه.

## ملاحظة مهمة عن البيانات
البيانات تُحفظ في متصفح المدرس (localStorage) ولا تُرفع للسيرفر. خذ نسخة احتياطية من الإعدادات دورياً.
لمزامنة بين أجهزة متعددة أو دخول أكثر من مدرس نحتاج إضافة واجهة خلفية (PHP + MySQL على نفس الاستضافة).
